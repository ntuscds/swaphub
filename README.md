# SwapHub
Telegram app to help you find indexes you want.

## Major Pain Points
During Add/Drop, we can find someone to swap index with. We have to:
- *Manually* sift through telegram groups / connections to find a swap.
- Manage who has already swapped, and who hasn't.

## Testing

The authenticated application and Convex backend live in `ui/`. See
[the UI testing guide](ui/README.md) for fast local tests, isolated database
fixtures, and the Docker-backed browser suite. The product scenarios are defined
in [the E2E test plan](plans/E2E_TESTS.md).
